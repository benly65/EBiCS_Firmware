# Startup torque offset averaging tweaks (delay + offset delta)

This commit keeps the simple startup approach (fixed delay + averaging), but moves tuning values to `Inc/main.h`
so you can tweak them quickly during real-world tests.

## What changed

### 1) Startup delay before averaging
**Before:** fixed delay right before averaging ADC offsets.

**After:** the delay is controlled by a define:

```c
HAL_Delay(TORQUE_OFFSET_STARTUP_DELAY_MS); // [ms]
```

This delay happens **right before** averaging phase current offsets and `MP.torque_offset`.

### 2) Reset torque accumulator before averaging
We explicitly reset the torque sum accumulator before the 32-sample averaging loop:

```c
temp4 = 0; // reset torque sum accumulator (torque ADC)
```

Without this, `temp4` could contain garbage/old value (depending on how it was previously used),
which would corrupt the computed `MP.torque_offset`.

### 3) Torque zero margin (noise safety)
Instead of a hardcoded `+5`, the extra margin is controlled by a define:

```c
MP.torque_offset = (temp4 >> 5) + MP_TORQUE_OFFSET_DELTA;
```

This adds a small margin to the measured torque ADC zero to reduce false torque due to noise.

## Parameters (Inc/main.h)

```c
#define TORQUE_OFFSET_STARTUP_DELAY_MS  2000u  // [ms] Delay before averaging phase & torque ADC offsets
#define MP_TORQUE_OFFSET_DELTA          5u     // [ADC counts] Added to measured torque zero (noise margin)
```

## Notes

- `Inc/config.h` is generated by the Java configurator and is **not** part of this commit.
- The **torque override / throttle override switch** is introduced in the next commit.
